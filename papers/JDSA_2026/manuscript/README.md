# JDSA editable manuscript sources

`main.tex` uses the official Springer Nature class with `iicol`; `supplement.tex` produces Online Resource 1 (`ESM_1.pdf`). All editable dependencies are flat in this directory. Run `bash build.sh` to build identified and anonymous fallback PDFs. The class and bibliography style are unmodified publisher files. Source packages include the compiled BBLs.
