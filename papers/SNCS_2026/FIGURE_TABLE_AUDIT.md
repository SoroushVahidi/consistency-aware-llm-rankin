# Figure and Table Audit (Stage 3; Stage-5 reassessment appended)

Surveys every repository figure/table artifact that is a plausible
candidate for this manuscript, against `MANUSCRIPT_PLAN.md` Section 5's
planned list (F1-F5, T1-T4) and `EVIDENCE_MAP.md`'s "Planned tables" /
"Planned figures" tables. No figure or table is inserted into `main.tex`
this stage -- Stage 3 drafts Methodology only, and figure/table population
belongs to the Results stage (Stage 4+). This document is the handoff:
what exists, its quality, what it needs, and where it goes.

**Stage-5 reassessment (2026-07-31, after Discussion/Limitations were
drafted):** re-read all five figure captions and all six table captions
in `manuscript/main.tex` in the context of the completed Discussion,
checking specifically: caption self-containment; whether any caption or
visual encoding implies statistical significance where the corresponding
prose states none (`grep` for "significant" outside a Holm/"not"/count
context returned zero matches -- every occurrence is already
appropriately qualified); whether Figure~5 (exact-vs-greedy structural
gap) could be read as implying a retrieval-level conclusion from a
structural one (its caption is purely structural -- "confirming that
greedy over-removes rather than under-removes edge weight relative to the
true optimum" -- and makes no retrieval claim, so no change needed); and
whether Figure~4's sign-colored bootstrap forest plot (point estimates
colored by sign, not by significance) could be misread as a significance
encoding (the caption states directly that "nearly every interval
includes zero," which is the significance-relevant fact, so the color
encoding is not the reader's only cue). **No figure was regenerated and
no caption was changed as a result of this reassessment** -- all were
already written to this standard in Stage 4. No new figure was added; a
compact "structural objective versus retrieval objective" conceptual
figure was considered per the Stage-5 brief's suggestion and declined,
since Section~\ref{sec:extraction-eval}'s existing prose (the paragraph
ending "Whether the two are empirically linked...") and
Section~\ref{sec:discussion-mechanism}'s prose already state that
distinction in words precisely enough that a diagram would duplicate,
not add to, the pipeline figure (Figure~1) and the existing text.

All figures inspected below were generated by
`papers/JDIQ_2026/manuscript/figures_v2/generate_figures.py` using a
shared, colorblind-validated style module
(`papers/JDIQ_2026/manuscript/figures_v2/style.py`: fixed per-dataset
Okabe-Ito palette, `REGIME_LABELS`/`REGIME_LABELS_SHORT` mapping the
`ms2`/`ms1`/`ms1_drop_mutual` regime codes used in this manuscript's prose
to human-readable labels "Two-vote"/"One-vote"/"One-vote, mutual pairs
removed" -- this is a presentational choice, not a terminology
inconsistency; the correspondence should be stated once in the Results
prose the first time a figure is referenced, e.g. "the permissive regime
(`ms1`, labeled `One-vote` in figures)"). Vector PDF and raster PNG are
both produced per figure; **the PDF must be the one included in
`\includegraphics`** (vector, scales cleanly in print; the PNG is a
preview convenience only).
