Manuscript figures (Stage 4), per `../EVIDENCE_MAP.md` and
`../FIGURE_TABLE_AUDIT.md`.

- `f1_pipeline.{pdf,png}` -- pipeline/audit schematic with the dual
  greedy/exact repair branch. Generated by `generate_f1_pipeline.py`
  (schematic only, no underlying data table), per
  `../figure_prompts/f1_pipeline_dual_repair.md`.
- `f2_bm25_share.{pdf,png}` -- conditional BM25 edge-weight share, raw vs.
  normalized. Copied unchanged from
  `papers/JDIQ_2026/manuscript/figures_v2/fig2_bm25_share.pdf`; already
  publication quality and generated from the same canonical
  `reports/full_calibrated_core/` data this manuscript cites.
- `f3_cycle_decomposition.{pdf,png}` -- cyclic-query percentage before/after
  mutual-pair deletion, by dataset. Copied unchanged from
  `papers/JDIQ_2026/manuscript/figures_v2/fig5_cycle_decomposition.pdf`,
  same reasoning as F2.
- `f4_bootstrap_forest.{pdf,png}` -- repaired-minus-unrepaired paired
  bootstrap $\Delta$nDCG forest plot (active `ms1` regime, primary
  five-pair method family). Copied unchanged from
  `papers/JDIQ_2026/manuscript/figures_v2/fig7_bootstrap_forest.pdf`, same
  reasoning as F2.
- `f5_exact_vs_greedy_gap.{pdf,png}` -- exact-vs-greedy structural gap
  (mean feedback-arc weight removed, cyclic queries only), a new appendix
  figure with no prior artifact. Generated by
  `generate_f5_exact_vs_greedy_gap.py` directly from
  `reports/exact_open_source_ilp_repair_investigation/tables/structural_per_query.csv`,
  per `../figure_prompts/f5_exact_vs_greedy_gap.md`; its per-dataset
  numbers were cross-checked against that report's own
  `FINDINGS.md` table before use (see `../RESULTS_CROSS_CHECK.md`).

`style.py` is copied from `figures_v2/style.py` with one change: the
single-column figure width constant is resized from ACM's 3.35in text
column to `sn-jnl.cls`'s single-column text width (~5.10in; this
manuscript does not use the class's `iicol` two-column option). Palette,
regime labels, and every other convention are unchanged, so new figures
stay visually consistent with the reused ones.

All PDFs are vector (`pdf.fonttype`/`ps.fonttype` = 42, i.e. embedded,
non-rasterized text); PNGs are 300 DPI preview-only convenience copies,
never the file referenced by `\includegraphics`.
