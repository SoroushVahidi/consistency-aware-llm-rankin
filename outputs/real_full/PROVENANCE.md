## Directory Structure

Each preference source now has its own sub-directory:

```
outputs/real_full/
├── run_manifest.json                          ← run parameters + per-dataset status
├── <dataset>/
│   ├── qrels/
│   │   ├── <dataset>_per_query.csv            ← per-query × per-method metrics
│   │   ├── <dataset>_summary.csv              ← aggregate per-method statistics
│   │   ├── <dataset>_experiment_summary.json  ← high-level metadata
│   │   ├── timings/
│   │   │   ├── <dataset>_timings.csv
│   │   │   └── <dataset>_timings.json
│   │   └── bootstrap/
│   │       ├── <dataset>_qrels_bootstrap_ndcg_at_k.json
│   │       └── <dataset>_qrels_bootstrap_ndcg_at_k.csv
│   └── qrels_flip/
│       └── <same structure as qrels/>
```

This layout prevents the overwrite bug where both `qrels` and `qrels_flip` runs
previously wrote to the same `outputs/real_full/<dataset>/` directory.

## Data Source

All results use **proxy (synthetic) data** generated by
`scripts/generate_proxy_datasets.py` (seed=42).  Real HuggingFace data was
unavailable in the offline execution environment; the proxy pipeline was the
configured fallback.

Proxy dataset sizes:

| Dataset   | Queries generated | Queries sampled | top-k |
|-----------|------------------|-----------------|-------|
| SciDocs   | 500              | 50              | 20    |
| FiQA      | 648              | 50              | 20    |
| HotpotQA  | 500              | 50              | 20    |
| BRIGHT    | 100              | 50              | 20    |

## Methods Evaluated

All 12 methods are present in every per-query CSV:

| Method                               | Type           |
|--------------------------------------|----------------|
| `score_sum`                          | Baseline       |
| `borda`                              | Baseline       |
| `pagerank`                           | Baseline       |
| `greedy_fas_topological`             | FAS-repair     |
| `greedy_fas_weighted_balance`        | FAS-repair     |
| `greedy_fas_copeland`                | FAS-repair     |
| `greedy_fas_score_augmented_topological` | FAS-repair |
| `fas_balance_score_prior_alpha_beta` | FAS-hybrid ★  |
| `hybrid_rrf_fas_regularized`         | FAS-hybrid     |
| `hybrid_rrf_balance_a05`             | FAS-hybrid     |
| `hybrid_rrf_copeland_a03`            | FAS-hybrid     |
| `hybrid_rrf_priority_topo_a03`       | FAS-hybrid     |

★ `fas_balance_score_prior_alpha_beta` (alpha=0.5, beta=1.0) was added to the
real pipeline in this PR.  It uses the repaired graph's balance scores plus the
original graph's score-sum as a prior:
`score = 1.0 × norm(balance_repaired) + 0.5 × norm(score_sum_prior)`.
