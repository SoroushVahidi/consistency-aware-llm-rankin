## Reading this table honestly

- **No slice clears `PROCEED_TO_LABELING`** at the pre-registered
  `headroom_threshold=0.01` / `min_heterogeneity_fraction=0.05` gate-0
  settings (see `scripts/run_oracle_headroom_analysis.py --help` for how to
  change either). This is a real result, not an artifact of a badly chosen
  threshold: `0.01` was chosen to match the manuscript's own established
  practical-significance margins (its equivalence-testing margins are
  0.005-0.01; its own MDE analysis found median observed |Δ| = 0.0036 vs.
  an 80%-power MDE of 0.0207 in the larger-pool family) -- see
  `docs/research/RESEARCH_TRAJECTORY.md` §3.
- `scidocs` cleanly fails the gate (CI upper bound 0.0087 < 0.01) --
  consistent with the manuscript's own null finding for this exact
  dataset/regime.
- `fiqa`, `hotpotqa`, `bright` are `AMBIGUOUS`, not `NO_HEADROOM` --
  their CIs straddle the threshold, mostly because n is small (50-120
  queries per slice) relative to a headroom effect this size. This is
  the correct, honest reading: "not enough evidence either way at this
  sample size," not "no effect."
- Per-query heterogeneity (both a beneficial and a harmful fraction
  clearing 5%) IS present in the slices checked (see individual
  `REPORT.md` files) -- the bottleneck is confidence-interval width at
  this n, not an absence of heterogeneity.

## Next step this analysis motivates

Per the gate-0 decision rule, the honest next step for the `AMBIGUOUS`
slices is **more query volume on the same already-existing outcome
tables** (e.g. add `ms2`/`ms1_drop_mutual` regimes, additional pool_ids, or
additional pair_names from the same committed
`pool_robustness_paired_deltas.csv`, or pool across regimes/pools within a
dataset) before concluding either way -- not immediately jumping to
feature/model work. See `docs/research/EXPERIMENT_ROADMAP.md` Phase 1.

## Reproduce

```
python scripts/run_oracle_headroom_analysis.py \
    --dataset <scidocs|fiqa|hotpotqa|bright> --regime ms1 \
    --pool-id rrf_union_topk --pair-name copeland_graph \
    --output-dir <output-dir>
```

Each subdirectory's `MANIFEST.json` records the exact input CSV SHA-256,
filters, and full numeric result for independent verification.
